# Board & Staff photos

Drop each person's photo in this folder, named exactly as listed below (lowercase,
`.jpg`). The About page shows the photo automatically; if a file is missing, a tidy
initials circle is shown instead — so the page always looks complete.

Square photos look best (they're cropped to a circle). ~400×400px is plenty.
