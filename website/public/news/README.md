# News images

Drop each news entry's photos into its matching folder here, e.g.:
  public/news/dec-2024/hatten-thank-you.jpg

Then set the `src` for that image in  src/data/news.ts  to:
  "/news/dec-2024/hatten-thank-you.jpg"

Folder = the entry's `slug` in news.ts. Order of images in news.ts = display order.
